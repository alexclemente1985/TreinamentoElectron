# Projetos Electron & React

## electron-vite
- Gerenciador de projetos electron
-<https://electron-vite.org/>

### Criando projeto electron:

- `npm create @quick-start/electron@latest`
- Insira as informações do projeto na sequência;
-- *Electron updater plugin*: permite surgimento da modal de atualização de aplicativo (necessário possuir certificado de desenvolvedor, que é pago);
-- *Electron download mirror proxy*: para o caso de baixar dados a partir de algum proxy

### Roteamento
-<https://electron-router-dom.daltonmenezes.com/pt>
-`npm install electron-router-dom`

### Biblioteca de ícones
-`npm install phosphor-react`

### Estilização de acordo com S.O.
-`npm install clsx`

### Menu colapsável
-`npm i @radix-ui/react-collapsible`
